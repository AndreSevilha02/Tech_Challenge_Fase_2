Classificando a Qualidade de Vinhos com Machine Learning

Este projeto tem como objetivo desenvolver um modelo de classificação capaz de prever a qualidade de vinhos com base em suas características físico-químicas (acidez, teor alcoólico, densidade, dióxido de enxofre, entre outras), utilizando o Wine Quality Dataset.

A variável de qualidade original foi transformada em uma classificação binária:

Alta Qualidade: nota ≥ 7
Baixa/Média Qualidade: nota < 7

O projeto contempla todo o pipeline de ciência de dados, incluindo:

Análise Exploratória de Dados (EDA)
Pré-processamento e engenharia de features
Treinamento e comparação de modelos de classificação
Avaliação de desempenho com métricas apropriadas
Interpretação dos resultados e principais variáveis que influenciam a qualidade do vinho
